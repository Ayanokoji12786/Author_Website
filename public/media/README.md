# Mountain landscape

`mountain-dawn.webp` (1536 × 1024) and `mountain-dawn-mobile.webp` (900 × 600)
are optimized versions of an image generated for this redesign. They provide
atmospheric scenery only; they are not the book's original cover, author imagery,
or a photograph documenting a specific place. The same scene is exposed differently
at the opening and closing of the site. No text is baked into these images.
